# 🎨 AI Image Generator

A powerful, React-based web application that allows users to generate high-quality images from text prompts. By integrating the **OpenAI DALL-E API** and **Hugging Face Inference API**, this tool turns creative ideas into digital art instantly.

🔗 **Live Demo:** [View Live Site](https://your-deployment-link.vercel.app/)

---

## 🚀 Features

✅ **Text-to-Image Generation** – Transform descriptive text into unique visual assets.
✅ **Dual API Support** – Integration with both OpenAI and Hugging Face models for diverse styles.
✅ **Real-time Loading State** – Interactive loading animations and progress indicators.
✅ **Responsive UI** – Fully optimized for mobile, tablet, and desktop viewing.
✅ **One-Click Download** – Easily save your generated artwork to your local device.
✅ **Secure API Handling** – Uses environment variables to keep sensitive API keys protected.

---

## 🛠️ Tech Stack

### Frontend
* ⚛️ **React.js** – Frontend framework
* 🎨 **CSS3** – Custom styling and animations
* ⚡ **Vite** – Fast build tool and development server

### AI Models & APIs
* 🤖 **OpenAI DALL-E API** – For high-fidelity image generation.
* 🖼️ **Hugging Face Inference API** – Access to Stable Diffusion models.
